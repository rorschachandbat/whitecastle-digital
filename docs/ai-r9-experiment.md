# r9 高分先验与训练诊断

2026-11-13，环境 `local-practice-v1`。r8已停止，检查点和原始日志保留。规则引擎、卡牌和终局计分没有修改；本次改变的是教师、公开特征、搜索截断估值和学习辅助任务。

## 做了哪些改进

- `data/ai-heuristic-r9.json` 提高家臣晋升和武士乘分的软偏好，根据当前资源与人员判断收益；个人面板只计算实际执行排，补上该排真实资源收益。
- `public-decisions-v4` 在原2345维之后追加双方各6个结构特征，状态2357维、候选160维。编码指纹绑定特征、环境、高分估值和攻略源码；旧数据不能混训。
- 搜索到达预算后先完成当前连锁，再比较引擎阶段分加公开乘分潜力。潜力不加入终局训练奖励，终局严格归零。额外160次选择仍不能结束连锁时记为失败，不填零分。
- 策略/价值网络增加七分项辅助头，标签为真实终局分项；高分教师样本温和增加模仿权重，保留普通局。总奖励仍是自身实际终局分数/80，不封顶。
- 记录双方每步选择、实际下标、候选数、前三候选及启发式、网络价值分、策略/实际采样概率与熵、搜索起止结果、分项MSE、优势和梯度。动作边界记录资源、家臣位置数量、武士价值及已兑现分数。
- 恢复训练的 `.progress.json` 按种子累积，不再每次只留下最后一局；完整终局经验仍按局压缩保存。

这些先验来自已审计样本的得分结构，不是把真人完整轨迹监督进网络。真人计分审计与123分样例的等价路线见 [规则审计](bga-rule-audit.md)，批量真人完整动作标签仍未完成。

## 当前瓶颈与下一步实验

10个学习席位终局平均只有1.6名城内家臣，1.9名家臣留城门，武士价值合计平均3.4；6个席位仍有至少2珍珠母。这提示资源转化与晋升机会值得检查，不能仅凭终局资源断言某一步应该晋升。

优先用逐步日志定位三种现象：

1. 手中有资源但没有获得相应行动：检查放骰根候选与搜索续行，比较先取资源和先拿行动的路线。
2. 已获得家臣行动却放弃晋升：检查合法选择、即时费用、前三候选与实际选择；必要时增加关键连锁的教师搜索，另建数据版本。
3. 城内家臣、武士价值只展开其中一边：按轮比较部署结构和终局分项，确认先验是否过度追求单一人数或即时奖励。

正式预算先扩大为4×2、120/8，每代32训练局、16对换座种子，保留0.25分晋级阈值。它能减少小预算截断，但仍由攻略续行；若选模表现持续与冠军相同，应先检查根候选覆盖、教师质量和更长连锁，不能只延长训练时间。完整4×2、120/8在一个公开根的测量耗时18.2秒、404节点、8截断、0失败；整代耗时尚未测完。8×4、300/18深搜配置尚未实测。

## 规则搜索并行基准（2026-11-13）
