# 工具脚本 CHANGELOG

## 2026-11-11 — 持续训练与局面分析

- 新增 `train-loop.py`，按完整对局保存、支持重启恢复、历史对手、攻略回归门槛、选模评估和存储上限。
- 新增 `train-ai.ps1`，提供 Start/Stop/Status，路径相对脚本和输出目录可配置。
- 新增 `analyze-position.py`，通过 JSON 行协议恢复本地存档并输出候选策略排序；策略权重不冒充胜率。
- `evaluate-ai.py` 提供可复用的评估函数；`train-policy.py` 支持混合历史对手与逐局压缩经验保存。

## 2026-11-11 — AI 训练与评估

- 新增 `ai-common.mjs`、`ai-env-server.mjs`，用本地 JSON 行协议把 Python 训练连接到 JS 规则环境。
- 新增压缩数据生成、目录/权重哈希绑定、背压、独立评估、检查点与恢复训练。
- `train-policy.py` 训练策略/价值网络；`evaluate-ai.py` 报告交换座位后的胜率、分数和分差。

## 2026-11-11 — 本地练习服务

- 新增 `serve-play.mjs` / `npm run play`，绑定127.0.0.1，端口参数默认4176；同时提供页面、配置编辑器和本机boardgame.io会话API。
- 静态资源白名单、请求来源检查、5MB请求上限与24会话上限；不公开原图、私人资料或整个仓库，不调用Vite或编译。
- 从脚本位置定位根目录；跨分支复制须保留 `play.html`、`config-editor.html`、src、data和依赖锁文件的相对布局，通过npm安装依赖，不依赖dist目录。
- 检查脚本纳入对局、动作向导、服务和play文案。已通过语法、项目检查及浏览器服务访问；生产构建未执行。

## 2026-11-11 — 非构建检查入口

- `check-project.mjs` 检查规则/开发文档、模块 CHANGELOG、页面本地导入、StringTable 引用与 Markdown 本地文件链接。
- 从脚本位置推导根目录，不硬编码分支或本机路径；可以从其他目录执行。
- 脚本需要与仓库的 `src/`、`docs/` 和 `package.json` 一起使用，不能只复制脚本单文件运行。
- 不执行构建、网络请求或文件修改。
- 推荐在仓库根运行 `npm run check`，在其他目录运行 `node <工作副本>/scripts/check-project.mjs`。
- 检查只涵盖结构和已识别的文案键、链接文件存在性，不验证外链及标题锚点，不等于完整 UI 或规则验证。
