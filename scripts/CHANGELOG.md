# 工具脚本 CHANGELOG

## 2026-11-11 — 用户授权的BGA回放原始库

- 用户告知取得BGA同意后，增加仅依赖Python标准库的 `crawl-bga.py`；Cookie从本机忽略文件读取，不进入代码、日志或资料库。
- 分页发现指定玩家已结束的姬路城记录，按真实回放链接提取初始局面与结构化事件；gzip JSON逐局保存，原子清单、SHA-256、文件锁和STOP支持断点恢复。
- 默认两线程共享一秒请求间隔，429/5xx有限退避，认证或访问拒绝停止；未就绪档案按网站原有入口有限准备。
- 支持新版集中配置和旧版分散标记，配置缺项明确记录；实际新/旧样例分别读出179/502包和终局，11项离线测试通过。支持gzip压缩传输减少页面下载体积。原始数据明确不能直接训练，推荐人工抽查网页及解压文件；未构建。

## 2026-11-11 — 修订4全新训练默认路径

- 持续训练配置、PowerShell启动器和Python CLI默认改用 `continuous-r4`、`guide-r4`；保留旧模型兼容拒绝机制，不更改训练算法。
- 新数据由调用命令显式产出，不覆盖已存在文件，脚本从自身位置解析项目路径，跨分支同布局可用。
- 124项Node测试、6项Python测试及项目静态检查通过；推荐检查生成report与 `loop-state.json` 后再评估。未运行项目构建。

## 2026-11-11 — BGA观察导入命令

- import-bga-replay.mjs从自身位置寻找同副本目录，输入输出相对调用者，拒绝覆盖已有输出；可另传计分前观察进行独立计分对账。
- serve-play.mjs增加本地观察页白名单，仍不编译、不构建。
- 私人输入输出仅放.local，不上传对局原始记录。


## 2026-11-11 — 持续训练与局面分析

- 新增 `train-loop.py`，按完整对局保存、支持重启恢复、历史对手、攻略回归门槛、选模评估和存储上限。
- 新增 `train-ai.ps1`，提供 Start/Stop/Status，路径相对脚本和输出目录可配置。
- 新增 `analyze-position.py`，通过 JSON 行协议恢复本地存档并输出候选策略排序；策略权重不冒充胜率。
- `evaluate-ai.py` 提供可复用的评估函数；`train-policy.py` 支持混合历史对手与逐局压缩经验保存。

## 2026-11-11 — AI 训练与评估

- 新增 `ai-common.mjs`、`ai-env-server.mjs`，用本地 JSON 行协议把 Python 训练连接到 JS 规则环境。
- 新增压缩数据生成、目录/权重哈希绑定、背压、独立评估、检查点与恢复训练。
- `train-policy.py` 训练策略/价值网络；`evaluate-ai.py` 报告交换座位后的胜率、分数和分差。

## 2026-11-11 — 非构建检查入口

- `check-project.mjs` 检查规则/开发文档、模块 CHANGELOG、页面本地导入、StringTable 引用与 Markdown 本地文件链接。
- 从脚本位置推导根目录，不硬编码分支或本机路径；可以从其他目录执行。
- 脚本需要与仓库的 `src/`、`docs/` 和 `package.json` 一起使用，不能只复制脚本单文件运行。
- 不执行构建、网络请求或文件修改。
- 推荐在仓库根运行 `npm run check`，在其他目录运行 `node <工作副本>/scripts/check-project.mjs`。
- 检查只涵盖结构和已识别的文案键、链接文件存在性，不验证外链及标题锚点，不等于完整 UI 或规则验证。
