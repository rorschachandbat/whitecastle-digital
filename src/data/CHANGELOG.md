## 2026-11-11 — 两人版可编辑数据目录

- 新增 `whitecastle-2p.json` 的结构校验与配置指纹工具。
- 固化已核验的个人面板、10 张花园牌和 16 个训练场单面；训练场 8 个实体的正反配对保留为空，避免按编号猜测。
- 城堡牌、起始牌和训练场实体配对继续标记为待核验，不进入规则计算。
- `validateCatalog` 检查两人边界、资源上限、效果类型、费用、来源、唯一 ID 和 Token 面引用。
- 训练实体配对必须为一个蓝色行动面和一个黄色收益面；重复面或两个同色面不能通过校验。
- 个人面板只接受三种明确的人员/骰色对应，未知排不能通过缺失颜色绕过校验。
- 实际检查：7 项目录测试通过，包含 SHA-256 稳定性、非法数据拒绝及 StringTable。
- 该模块只负责资料配置，不代表完整规则引擎已经实现。
