# 游戏模块 CHANGELOG

## 2026-11-11 — boardgame.io本地双人对局

- 新增 `createLocalGame`、`localClient.js`，move调用同一纯规则，按选牌、常规及轮末决策者同步框架当前玩家，第三轮结束返回赢家。
- 使用已发布的CommonJS公共Client入口，不需要编译；对框架Immer状态使用JSON快照跨越纯引擎边界，非法move保持状态不变。
- 恢复客户端时重放已校验动作；撤销重建同一目录及种子的Client。
- 实际验证：4项真实Client回归通过，覆盖18次放骰终局、G/ctx同步、错误原子性和存档恢复；浏览器已验证选牌及训练场连锁。未构建、部署或接入联网多人。

## 2026-11-11 — 接入 boardgame.io 骨架

- 新增 `game.js`，定义可序列化的状态格式版本、两名玩家和规则文档入口。
- 当前 `mode=scaffold`，不开放游戏动作或客户端回合事件；不声称已经实现两人版玩法。
- 没有从参考 C# 项目复制代码或牌数据。
- 对应规则：规则模型实施前置条件；具体玩法待 `docs/RULES.md` 的规则编号逐项实现。
- 检查：通过不触发构建的 Node 测试验证真实 Client 初始化、动作集合和 JSON 序列化；结果以根 CHANGELOG 为准。
- 推荐验证：用户授权构建后检查页面状态面板；实现第一批规则时先补合法与非法输入场景。
