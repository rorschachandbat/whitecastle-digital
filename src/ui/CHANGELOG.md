# 网页界面模块 CHANGELOG

## 2026-11-11 — 建立规则工作台

- 建立原生 JavaScript 界面，显示项目阶段、框架状态、规则入口和实施路线。
- 玩家可见文案集中于 `StringTable.js`，标题、按钮、说明和错误提示均通过键读取。
- 状态导出使用浏览器本地文件下载，不调用 Yucata 或其他对局服务。
- 在页面显式说明当前不能完整对局，导出的框架状态不是游戏存档。
- 文档通过 Vite 原始文本导入后以纯文本显示，不解释外部 HTML。
- 检查：静态语法、StringTable 键引用及 Node 单测；未启动 Vite 或浏览器预览。
- 推荐验证：用户运行开发服务器后检查窄屏布局、五个文档入口、状态导出和键盘操作。

## 2026-11-11 — 两人版配置编辑器

- 新增 `config-editor.html` 和 `configEditor.js`，提供卡牌、训练场单面和个人面板的可视化预览及 JSON 编辑。
- 支持校验、浏览器草稿、导入、导出、修订号和配置 SHA-256 指纹。
- 所有待核验项保持显式状态；编辑器不会把未确认的训练场正反配对或牌组内容伪装成完成。
- 页面标题、项目阶段和路线已同步到“两人规则核心第一批”；路线单独列出合法动作、网页棋盘、Yucata 复盘和 AI。
- 已通过本地静态服务浏览器验证：默认数据加载、个人面板收益、来源和训练配对待核验状态可见。
