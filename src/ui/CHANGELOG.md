## 2026-11-11 — 建立规则工作台

- 建立原生 JavaScript 界面，显示项目阶段、框架状态、规则入口和实施路线。
- 玩家可见文案集中于 `StringTable.js`，标题、按钮、说明和错误提示均通过键读取。
